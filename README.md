# Rogue Roomba

> Vacuum a haunted house where your battery drains from fear.

A top-down survival game where you pilot a nervous robot vacuum through rooms full of dust, ghosts, and cursed electronics. Charging is safe, but light is scarce and every hum sounds like a ghost.

## Features
- Navigate rooms with limited battery
- Eat dust bunnies to restore charge
- Avoid ghosts that drain power by sight
- Unlock new vacuum shells with collected batteries

## Stack
- Godot
- GDScript
- Tiled

## Getting started
```
Import the Godot project, open main.tscn, and press F5. Use WASD or arrow keys to move and Space to vacuum dust.
```
